# NovaOS roadmap

## Phase 1 · 0.1.0 Alpha

- [x] Implement the Debian live-build repository and remote ISO workflow.
- [x] Add branded GRUB, Plasma desktop defaults, SVG assets, and dark/light color schemes.
- [x] Select system, network, audio, and desktop application packages.
- [x] Add source and ISO verification plus diskless VM test instructions.
- [x] Trim default apps, audit the package and startup inventories, and add Nova Performance and Nova Store.
- [ ] Build and collect the verified ISO from GitHub Actions.
- [ ] Pass the VirtualBox graphical desktop checklist under BIOS and UEFI.

## Later phases

- Develop a NovaOS Plasma theme with its own panel, control center, icon design, and motion.
- Measure gaming performance, power use, and cold boot time on reference hardware.
- Design native Qt/QML interfaces for NovaOS-specific tools.
- Evaluate an installer, persistent storage, update policy, and wider hardware coverage.
