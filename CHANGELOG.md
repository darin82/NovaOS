# Changelog

## 0.1.0 Alpha · first release target

- Refined the wallpaper and shared native controls, branded boot and sign-in, and fixed the Minimal profile Music launcher.

- Added Nova Installer, first-boot Welcome, Recovery tools and update notifications.

- Added opt-in Nova AI with streamed local and cloud responses, secure credential handling, and a confirmation-based system action palette.

- Added Nova Music and replaced the initial Store menu with a native APT and Flatpak application catalog.

- Added Nova Gaming Hub, optional gaming and recording tools, native Steam discovery, per-game boost, and MangoHud configuration.

- Added bounded ZRAM, an on-demand Performance Center, reversible workload profiles, package size reports, and a Linux guest benchmark.
- Added CPU history and guest benchmark checks for display, networking, audio, and APT sources.

- Added the Nova system app suite with native KDE tools, Firefox ESR, branded launchers, shared icons, file associations, and on-demand signed Debian updates.

- Added Nova Quick Settings, independent appearance controls, an Ultra Lite appearance preset, and desktop shortcuts for new users.

- Reduced the default app set and disabled file indexing and sponsored browser content.
- Added Nova Performance profiles, on-demand LibreOffice installation in Nova Store, and release inventory and benchmark reports.

- Debian 13 amd64 live-image build with GitHub Actions artifact upload.
- NovaOS GRUB entries, release identity, launcher logo, and original Midnight Horizon wallpaper.
- Nova Midnight and Nova Daybreak Plasma color schemes and initial panel defaults.
- Plasma Wayland, Firefox ESR, Konsole, Dolphin, NetworkManager, PipeWire, APT, and Flatpak.
- Package manifest, SHA-256 checksums, and source, chroot, and image checks.
- Diskless VirtualBox acceptance checklist.
