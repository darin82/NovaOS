# NovaOS 0.1.0 Alpha license notices

The ISO contains Debian packages and NovaOS-specific configuration, scripts, and artwork. Debian package notices remain in `/usr/share/doc/<package>/copyright` in the image. The release includes copies of those notices and Debian's common license texts in `package-license-notices.tar.gz`. Consult `license-notice-index.tsv` for paths and any notices absent from the image.

`installed-packages.tsv` records installed binary packages, source package names, and versions. Use these together with the individual notices to identify the corresponding upstream source packages. Debian publishes source packages and source archives separately. [Debian Sources](https://sources.debian.org/)

The release does not assign a new license to third-party components, trademarks, or artwork.
